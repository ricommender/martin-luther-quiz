# ✳ Martin Luther – Lernquiz

Interaktive Lernwebsite für Religion, Klasse 4, Grundschule Baden-Württemberg.

## Inhalt

- 10 Lernkarten mit leicht verständlichen Erklärungen
- 10 Quizfragen mit sofortigem Feedback
- 12 zufällig ausgewählte Fragen in der Probe-Klassenarbeit
- Punkteauswertung und Wiederholungsmöglichkeit
- Optik angelehnt an Pauls Counter: dunkles Design, limettengrüne Akzente und große mobile Karten

## Spielen

Nach Aktivierung von GitHub Pages: https://ricommender.github.io/martin-luther-quiz/

Lokal genügt es, `index.html` im Browser zu öffnen. Kein Backend, keine Anmeldung, keine Datensammlung.

## GitHub Pages

Unter **Settings → Pages** **Deploy from a branch**, **main**, **/(root)** auswählen und speichern.

## Historische Einordnung

Die Veröffentlichung der 95 Thesen 1517 ist belegt. Der oft erzählte Anschlag an die Tür der Schlosskirche in Wittenberg ist historisch umstritten.
